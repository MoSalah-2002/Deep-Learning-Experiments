## 🚀 Getting started

```bash
git clone https://github.com/MoSalah-2002/Deep-Learning-Experiments.git
cd Deep-Learning-Experiments
python -m venv .venv
# Activate the environment, then:
pip install -r requirements.txt
jupyter notebook
```

Choose the PyTorch/Torchaudio build compatible with your system if you need GPU acceleration. Audio experiments may require local audio samples and pretrained checkpoints.

## 🔐 Security

Credentials found in the source material were removed from prepared copies where applicable. Use environment variables for any external service credentials; never commit tokens or private files.

## 📌 Reproducibility

These are independent educational experiments, not production speech systems. Runtime, model checkpoints, sample rate, and audio paths may need adjustment. Not every notebook has been executed end-to-end in a clean environment.
