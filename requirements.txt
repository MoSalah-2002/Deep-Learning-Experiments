## ⚡ Quick start

```bash
git clone https://github.com/MoSalah-2002/Deep-Learning-Experiments.git
cd Deep-Learning-Experiments
python -m venv .venv
# Activate the environment, then:
pip install -r requirements.txt
```

For audio notebooks, install the matching PyTorch/Torchaudio build for your hardware. Some notebooks also depend on local audio files or pretrained checkpoints that are not included.

## 🔐 Safe configuration

Credentials have been removed from the prepared notebook copies. Configure external service tokens using environment variables; never paste secrets into notebook cells or commit them to Git.

## 🧪 Reproducibility notes

- GPU acceleration is optional for the small educational examples but recommended for heavier models.
- Audio sample rates, file paths, and model checkpoints may need to be adjusted.
- The notebooks are exploratory and are not presented as production-ready speech systems.
